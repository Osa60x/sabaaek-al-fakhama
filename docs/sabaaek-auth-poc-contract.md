# عقد POC لمصادقة وإدارة سبائك الفخامة

هذا العقد خاص ببيئة `sabaaek-site-staging` وقاعدة `sabaaek_gold_staging` فقط. لا يُسمح له بقراءة مستخدمي الإنتاج أو تعديل Supabase أو عامل الإنتاج.

## الأدوار

| الدور | تغيير أسعار 24/21/18 | تغيير إعدادات الموقع | إدارة المدراء | سجل التدقيق | إدارة المالك |
|---|---:|---:|---:|---:|---:|
| زائر غير مسجل | لا | لا | لا | لا | لا |
| Manager نشط | نعم | لا | لا | لا | لا |
| Owner نشط | نعم | نعم | نعم | نعم | نعم |
| أي حساب غير نشط | لا | لا | لا | لا | لا |

## قواعد الجلسة

تُحفظ الجلسة في cookie باسم عشوائي، مع `HttpOnly`, `Secure`, `SameSite=Lax` ومدة انتهاء محدودة. لا يُحفظ التوكن أو كلمة المرور أو الدور في `localStorage` أو JavaScript. كل طلب إداري يعيد التحقق من الجلسة ومن حالة الحساب والدور على الخادم.

## المسارات المطلوبة

| المسار | الطريقة | المصادقة | الغرض |
|---|---|---|---|
| `/auth/login` | POST | عامة | تسجيل الدخول بعد تحديد معدل المحاولات |
| `/auth/logout` | POST | جلسة | إبطال الجلسة |
| `/auth/session` | GET | جلسة اختيارية | إرجاع هوية آمنة بلا أسرار |
| `/admin/price-adjustments` | GET | Manager أو Owner | قراءة التعديلات |
| `/admin/price-adjustments` | PUT | Manager أو Owner | تعديل العيارات المسموحة فقط |
| `/admin/site-settings` | PUT | Owner فقط | تعديل الثيم ووسائل التواصل |
| `/admin/managers` | POST/PATCH | Owner فقط | إضافة أو تعطيل Manager |
| `/admin/audit` | GET | Owner فقط | قراءة سجل التدقيق |

## حالات الرفض الإلزامية

يجب رفض الطلبات عند غياب الجلسة، انتهاء الجلسة، الحساب غير النشط، الدور غير الكافي، CSRF غير صحيح للطلبات المغيرة، جسم JSON غير صالح، عيار خارج `24/21/18`، تعديل خارج `-5000..5000`، أو محاولة Manager استدعاء مسار Owner.

## قرار أمني

لن تُنشأ واجهة إدارة عامة قبل نجاح اختبارات API المستقلة لهذه الحالات. Better Auth يمكن استخدامه كطبقة جلسات في POC، لكن لا يُعتمد نهائياً قبل التحقق من مخطط D1، batch operations، rate limiting، وإبطال الجلسة وتسجيل التدقيق.
