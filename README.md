# سبائك الفخامة — الاستضافة الثابتة

هذه نسخة HTML ثابتة مستقلة مهيأة لـ GitHub Pages. تجلب `XAU/USD` مباشرة من `api.gold-api.com` باستخدام CORS وذاكرة محلية مدتها 30 ثانية، ولا تتطلب خادماً أو مفتاحاً أو اشتراكاً.

## تحقق ما قبل النشر

قبل أي نشر يدوي، شغّل من جذر المشروع:

```bash
python3 tests/check_release_contracts.py
```

يتحقق العقد من بقاء عزل مشروع سبائك، ومسار QR حسب الاتجاه، والشعار الشفاف، وحركة التقليل، ومسار التخطّي للوحة المفاتيح، وحدود اللمس ورسائل الخطأ في لوحة الإدارة، ثم يقرأ النسخة المنشورة للتحقق من بقائها متاحة. لا يرسل النموذج بيانات دخول ولا يغير الأسعار أو إعدادات الموقع.
